# Simple Library System Management

A desktop library management application built with Java 21,
JavaFX, and Maven.

## Features
- Add, view, update, and delete books
- In-memory storage (no database)
- Basic input validation

## Requirements
- JDK 21
- Maven 3.9+

## Run
mvn clean javafx:run

## Note
Books are stored in memory and are lost when the application closes.
